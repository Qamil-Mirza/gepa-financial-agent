# Security Policy

## Supported versions

Only the `main` branch is supported. PitStop is pre-1.0 and has no released versions yet.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting: go to the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for security problems.

## Scope

PitStop handles your API keys locally and never sends them anywhere except the endpoints you configure.

## What not to post

Never paste API keys or the contents of your `.env` file into issues, pull requests, discussions or logs. If a key has been exposed, revoke it with the provider immediately.
